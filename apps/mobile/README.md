# Flutter app

The app currently includes sign-in/sign-up, secure token storage with refresh rotation, character discovery, character creation, conversation history and AI chat API integration.

## Generate native projects

The repository tracks Dart application code and package configuration. Native platform scaffolding is generated by Flutter during CI and must be generated locally before opening the app in Android Studio or Xcode:

```bash
cd apps/mobile
flutter create --platforms=android,ios --org com.alap.app .
flutter pub get
```

## Run

Android emulator:
```bash
flutter run --dart-define=API_BASE_URL=http://10.0.2.2:8000
```

iOS simulator / physical device:
```bash
flutter run --dart-define=API_BASE_URL=http://127.0.0.1:8000
```

Use an HTTPS API base URL for release builds. The value must be the API origin only; the client appends `/api/v1`.

## Verification

```bash
flutter analyze
flutter test
flutter build apk --release --dart-define=API_BASE_URL=https://api.example.com
```

The current CI compiles a debug Android APK. Release signing, iOS archive, device QA, push notifications, universal links, accessibility audits and store compliance remain separate release gates.
